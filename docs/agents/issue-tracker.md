# Issue Tracker: GitHub

Issues and specs for this repository live in GitHub Issues for
`shahvirb/espcontrol-jc4827w543r`. Use the `gh` CLI for tracker operations.

Pull requests are not treated as a triage request surface.

Wayfinder maps are issues labelled `wayfinder:map`. Their decision tickets are
child issues labelled `wayfinder:research`, `wayfinder:prototype`,
`wayfinder:grilling`, or `wayfinder:task`. Use native GitHub sub-issues and
issue dependencies where available; otherwise record the parent and blockers
in the issue body.

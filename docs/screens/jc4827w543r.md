# 4.3-inch JC4827W543R

The **Guition JC4827W543R** is a 4.3-inch landscape touchscreen powered by an
**ESP32-S3** processor. Its 480×272 display has room for **6 cards** on the
home screen.

## Install and Firmware Updates

Connect the display to your computer with a USB-C data cable, then install the
firmware below. Use this USB installer for later firmware updates too.

The JC4827W543R has 4 MB of flash and uses a single-app partition. EspControl's
firmware image does not fit in either slot of a dual-slot OTA layout, so native
ESPHome OTA, HTTP OTA, and browser OTA uploads are disabled for this device.
